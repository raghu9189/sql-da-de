# Practice Project 01

This directory contains SQL scripts and data for practicing SQL joins and window functions.

## Files
- `DDL.sql`: Data Definition Language script for creating schemas and tables.
- `*.csv`: Sample datasets including customers, employees, orders, order items, and products.
- `joins-practice.sql`: SQL scripts for practicing various `JOIN` operations.
- `window-funcs.sql`: SQL scripts for practicing window functions.
- `sql_window_functions_practice_dataset.sql`: Script to set up a dataset for practicing window functions.
