# SQL Data Analysis and Engineering (sql-da-de)

This repository contains SQL scripts and queries used for data analysis and data engineering tasks.

## Contents
- `Student.sql`: SQL scripts related to student data.
- `sales.sql`: SQL queries and schemas for sales data.
- `set_operations.sql`: SQL scripts demonstrating set operations.
- `tables.sql`: General table creation and structure scripts.
- `Customer Sales Project/`: A complete SQL project containing schemas, queries, and data on customer sales.
- `Questions Set 2/`: SQL query challenges and solutions involving correlated subqueries.
- `Questions Set 3/`: SQL query challenges and solutions involving window functions.

## Usage
You can run these SQL scripts against your database to create the necessary schemas and perform analysis.
